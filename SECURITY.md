# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and integrity of this project seriously.

If you discover a security vulnerability or sensitive data exposure, please DO NOT open a public GitHub issue. Instead, please report it privately:

- **Contact**: Reach out to the maintainer via GitHub issues with private advisory or direct contact.
- **Details to Include**:
  - Description of the vulnerability
  - Steps to reproduce
  - Potential impact
  - Suggested remediation (if known)

We will review your submission and respond within 48 hours.
