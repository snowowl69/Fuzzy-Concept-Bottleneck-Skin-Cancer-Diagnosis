# Contributing Guidelines

Thank you for your interest in contributing to the Fuzzy Concept-Bottleneck Skin Cancer Diagnosis project!

## Intellectual Property & Code Ownership

By contributing code, documentation, or other materials to this project, you agree that:
1. Your contributions will be licensed under the project's [MIT License](LICENSE).
2. You assert that you are the original author or have the legal right to submit the work.
3. Original attribution and copyright notices must remain intact.

## Workflow

1. **Fork the repository** on GitHub.
2. **Create a feature branch** (git checkout -b feature/your-feature-name).
3. **Commit your changes** with clear, descriptive commit messages.
4. **Run existing tests** to verify integrity:
   `ash
   pytest tests/
   `
5. **Open a Pull Request (PR)** against the main branch with a thorough explanation of changes.

## Code Standards

- Follow PEP 8 guidelines for Python code.
- Ensure all public functions and classes have descriptive docstrings.
- Add unit tests for new modules and features in 	ests/.
